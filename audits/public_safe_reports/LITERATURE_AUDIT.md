# Q311 · Source and prior-art audit

Checked 26 November 2026. **High confidence** in the source match and in the attribution of the proposed method. **Moderate confidence** that the sources searched contain no stated or completed algorithm for the full non-strict finite-assignment $d_2$ problem. The dissertation already proposes the route, and its established lemmas give the exact result once one proves that retaining all Bellman-minimizing transitions preserves precisely the globally optimal runs. The candidate completes that short bridge. Credit the source for the construction and characterize the contribution accordingly.

## Exact question

The pinned catalog asks for a single pair $\varphi,\psi$ built from finite language constants, variables, Boolean operations and left concatenation by a finite constant, over finite nonempty $\Sigma$. The input is an ordinary rational bound $p\ge0$. Each variable is assigned a finite subset of $\Sigma^*$, and the decision is whether $d_2(\sigma(\varphi),\sigma(\psi))\le p$. Complements are relative to $\Sigma^*$. Finite variable images and finite constants still allow infinite evaluated expressions, for example $\sim\varnothing$. The metric is
$$
d_2(K,L)=\tfrac12\sum_{w\in K\triangle L}(2|\Sigma|)^{-|w|}.
$$
The $\tfrac12$ factor gives mass one to $\Sigma^*$, and each word has strictly positive mass. This agrees with Marantidis §3.3, printed p. 48, and the recursive identity in Lemma 6.17, printed p. 103. Grammar (4.7) and Definition 4.9 on pp. 82–83 specify finite constants and finite variable images. The prose before (4.7) says “regular languages,” but the explicit instantiation sentence specifies finite languages. His §6.2 explains the right-concatenation version via word reversal. This is equivalent since reversal preserves lengths, finiteness and the symmetric difference. ## What the dissertation already gives

- **§6.2, Definition 6.3 and Lemma 6.4, printed pp. 94–96.** The original decision convention compares the cost strictly with $2^{-p}$. For $d_2$, finite and unrestricted assignments have the same **infimum** by truncation. Agreement through depth $h$ bounds the change by $2^{-h-1}$. This suffices for a strict threshold. It leaves the minimum question at equality. [Thesis PDF pp. 102–104](https://lat.inf.tu-dresden.de/research/theses/2019/Marantidis-Diss-2019.pdf#page=102)

For the single approximate equation, use the symmetric difference expression and a vacuous exact side condition. The $d_2$ treatment uses independent child transitions. The lemmas give the discounted recurrence, state-vector uniqueness by contraction, and exact rational LP values. Theorem 6.28 gives the exponential-time computation and EXPTIME-completeness for the preceding strict decision formulation. ## Exact implication of the established tools

This is an inference from the sources. Let $\mu(q)$ be the §6.3 per-state optimum, let $\beta=(2|\Sigma|)^{-1}$, and let $c(q)=\tfrac12\mathbf1_{q\in F_a}$ for the discrepancy set $F_a$. For a transition $q\to(q_a)_{a\in\Sigma}$, the exact rational gap
$$
c(q)+\beta\sum_a\mu(q_a)-\mu(q)
$$
is nonnegative by the Bellman recurrence. Over a run starting at $q_0$, summing these gaps with weights $\beta^{|w|}$ telescopes to the run's cost minus $\mu(q_0)$. The boundary term tends to zero because $0\le\mu\le1$ and the total level weight is $(|\Sigma|\beta)^h=2^{-h}$. Thus an optimal run starts at a minimum-value initial state and uses exclusively zero-gap transitions. Conversely, those two conditions give an optimal run. In the independent-transition formulation, a zero-gap transition takes a minimizing successor in each child direction. Keep **all** such transitions and all minimizing initial states. Keeping one representative optimal policy can discard a finite witness.

Apply Marantidis Lemma 3.43 to this restricted automaton and mark $B=\bigcup_i F_i$ for the original assignment variables. A run marks only finitely many nodes exactly when every original variable language is finite. Lemma 3.43 already decides this marked-state property for an arbitrary looping tree automaton. At $p=\min_{q\in I}\mu(q)$, its answer is the non-strict answer. Below this optimum the answer is negative, and above it truncation supplies a finite witness. [Exact recurrence, Lemma 6.18](https://lat.inf.tu-dresden.de/research/theses/2019/Marantidis-Diss-2019.pdf#page=112) · [Finite-marked-run test, Lemmas 3.43–3.44, printed pp. 73–74](https://lat.inf.tu-dresden.de/research/theses/2019/Marantidis-Diss-2019.pdf#page=81)

The candidate's two graph passes implement the same finite-marked-run property directly on its action graph. First find the invariant set where zero action remains optimal forever. Then compute the reachability attractor where one optimal action sends **every** child to an earlier stage. This is the standard finite reachability-game predecessor on a bipartite state/action arena. All finite assignments have a common depth beyond which every membership vector is zero. Simply requiring finitely many marks on each branch would be weaker. For example the marked nodes $a^nb$ for all $n\ge0$ form an infinite antichain, though each branch meets at most one. The Büchi test in Lemma 3.43 commits permanently to a clean cone and uses König's lemma on the prefix-closed precommitment region. [Marantidis Lemma 3.43](https://lat.inf.tu-dresden.de/research/theses/2019/Marantidis-Diss-2019.pdf#page=81) · [Holtmann, *Memory and Delay in Regular Infinite Games*, Algorithm 2.1, printed p. 21](https://publications.rwth-aachen.de/record/64650/files/3791.pdf)
